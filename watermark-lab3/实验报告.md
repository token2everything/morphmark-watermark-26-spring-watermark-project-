## 三、实验原理

### 3.1 离散余弦变换（DCT）

离散余弦变换（Discrete Cosine Transform, DCT）是一种实数域的正交变换，其变换核为实数余弦函数。对于图像处理，使用的是二维 DCT 变换。
DCT 变换后，图像的重要可视信息（能量）集中在**低频系数**中（左上角），而**高频系数**（右下角）的值通常非常小、接近于零，反映的是图像的细节和噪声部分。

### 3.2 水印嵌入原理

利用**人眼对图像高频成分的失真不敏感**这一特性，将水印信息嵌入到 DCT 变换域的高频系数中。

**嵌入流程：**

1. 将载体图像按 8×8 像素分块（256×256 → 32×32 = 1024 块）
2. 利用随机序列（固定种子 SEED=2026）在全部块中选择嵌入位置
3. 在选中块的 DCT **高频系数**位置（Zigzag 序号 58，块内坐标 (7,5)），根据水印比特修改系数：
   - 比特为 **1**：将该系数置为 **+α**（α = 80）
   - 比特为 **0**：将该系数置为 **-α**
4. 对所有修改过的块进行 IDCT 还原到空间域，得到含水印图像

**为什么选择高频系数嵌入：**
- DCT 高频系数本身接近零，修改后对图像整体视觉效果影响极小
- 人眼对高频细节的变化不敏感（视觉掩蔽效应）
- 高频系数的修改经过 IDCT 后，能量被分散到 8×8 块的所有 64 个像素上

### 3.3 水印提取原理

提取是嵌入的逆过程：

1. 对含水印图像同样进行 8×8 分块 DCT 变换
2. 使用相同的随机种子定位嵌入块
3. 在每个嵌入块的 DCT 系数 (7,5) 处，根据符号判断水印比特：
   - 系数 **> 0** → 比特 **1**
   - 系数 **≤ 0** → 比特 **0**
4. 按 UTF-8 解码还原为原始文本

### 3.4 Zigzag 扫描与频率分布

8×8 DCT 块的 Zigzag 扫描顺序如下（数值为序号 0~63）：

```
 0   1   5   6  14  15  27  28
 2   4   7  13  16  26  29  42
 3   8  12  17  25  30  41  43
 9  11  18  24  31  40  44  53
10  19  23  32  39  45  52  54
20  22  33  38  46  51  55  60
21  34  37  47  50  56  59  61
35  36  48  49  57  58  62  63
```

- **低频区**（0~10）：包含图像主要能量，左上角
- **中频区**（11~35）：过渡区域
- **高频区**（36~63）：细节信息，右下角。本实验选择序号 **58**（坐标 (7,5)）

## 四、实验步骤

### 4.1 水印预处理

```python
def text_to_bits(text):
    data = text.encode('utf-8')
    bits = []
    for byte in data:
        for i in range(7, -1, -1):
            bits.append((byte >> i) & 1)
    return bits
```

- "复旦大学" → UTF-8 编码 → 12 字节 → 96 比特
- 在数据前加 16 位长度头，共 **112 比特**需要嵌入

### 4.2 嵌入过程

```python
# 对蓝色通道 8×8 分块做 DCT
block = blue[y0:y0+8, x0:x0+8]
dct_block = dct(dct(block.T, norm='ortho').T, norm='ortho')

# 在高频位置 (7,5) 嵌入比特
if bit == 1:
    dct_block[7, 5] = 80    # +α
else:
    dct_block[7, 5] = -80   # -α

# IDCT 还原
idct_block = idct(idct(dct_block.T, norm='ortho').T, norm='ortho')
```

- 选择**蓝色通道**嵌入（人眼对蓝色分量变化最不敏感）
- 使用正交归一化 DCT（`norm='ortho'`）
- 嵌入强度 α = 80

### 4.3 随机嵌入位选择

```python
rng = np.random.RandomState(2026)
block_indices = rng.permutation(1024)[:112]
```

- 固定种子 2026 保证提取时可重现
- 112 个水印比特被随机散布在 1024 个块中

### 4.4 提取过程

```python
# 先读前 16 位 → 获取数据长度
# 再读全部 112 位 → 解码 UTF-8
if dct_block[7, 5] > 0:
    bits.append(1)
else:
    bits.append(0)
```

## 五、实验结果与分析

### 5.1 视觉质量

含水印图像与原始图像在视觉上**无法区分**。水印修改仅发生在 112 个 8×8 块的高频系数中，每个块修改 1 个系数。

| 原始图像 | 含水印图像 |
|:--------:|:----------:|
| ![原始](Lenna.bmp) | ![含水印](lenna_watermarked.bmp) |

### 5.2 客观质量指标

| 指标 | 数值 |
|------|------|
| **PSNR** | **42.54 dB** |
| 整体 MSE | 3.6201 |
| R 通道 MSE | 0（未修改） |
| G 通道 MSE | 0（未修改） |
| B 通道 MSE | 10.8603 |

- PSNR > 40 dB 表明含水印图像具有**极高保真度**，远超过 30 dB 的常规质量标准
- 仅 B 通道被修改，R、G 通道完全保留原始信息

### 5.3 水印提取结果

| 项目 | 结果 |
|------|------|
| 提取文本 | **"复旦大学"** |
| 数据长度 | 96 bits |
| 提取正确率 | **100%** |

全部 112 个比特（16 位长度头 + 96 位数据）均正确提取，无误码。

## 六、实验总结

本实验成功实现了基于 DCT 变换域的数字水印嵌入与提取算法。通过在载体图像 Lenna.bmp 的 DCT 高频系数中嵌入中文文本 "复旦大学"，验证了变换域信息隐藏技术的基本原理。

**实验结论：**

1. 利用 DCT 高频系数嵌入水印，可在保证图像质量（PSNR 42.54 dB）的前提下实现可靠的信息隐藏与提取
2. 随机序列选择嵌入位置增强了水印的安全性和不可感知性
3. 仅修改蓝色通道的策略充分利用了人眼对蓝色分量不敏感的特性，进一步降低了视觉影响
4. 提取正确率达到 100%，验证了算法的正确性和可靠性
